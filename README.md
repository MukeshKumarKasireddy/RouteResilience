# RouteResilience

AI-based disaster-resilient road network analysis and criticality assessment.

## Project Overview

RouteResilience analyzes satellite imagery to reconstruct road networks affected by occlusion or incomplete extraction and evaluates the resilience and criticality of the resulting road network.

## Project Structure

- `app/` — Application frontend and backend
- `ml/` — Machine learning and geospatial processing pipeline
- `tests/` — Project tests
- `docs/` — Architecture and research documentation
- `outputs/` — Generated predictions, graphs, and visualizations
